## Snake

Run the game with Python 3:

```console
python snake_game.py
```

The game opens in its own window. Use **W/A/S/D** or the arrow keys to steer and
**Q** to quit. **Restart Game** starts over, and **Automatic** lets the computer
play to the maximum score. Use **Slower** and **Faster** to adjust the game speed;
the current speed is displayed between the buttons. Manual mode ranges from
**0.1×** to **2.0×**, and automatic mode ranges up to **10.0×**. A graph of
balls eaten over time appears when a game ends and closes when you restart.
It uses only Python's standard library.

Run the tests with:

```console
python -m unittest discover -s tests
```
